# 고스트 카메라

갤럭시 탭과 Android 휴대폰에서 이전 사진을 반투명하게 겹쳐 보며 같은 구도로 다시 촬영하는 클로즈 베타 앱입니다.

## 현재 범위

- 실행 즉시 카메라 표시
- 기준 사진 여러 장을 한 번 등록해 순서대로 보관
- 촬영 화면에서 화살표 또는 번호 영역 스와이프로 `1 / N` 탐색
- 기준 사진 추가·삭제·순서 변경
- 고스트 투명도 조절
- 고스트 비율을 `채움`, `맞추기`, `늘리기` 중에서 선택
- 카메라와 고스트 구도를 0도, 90도, 180도, 270도로 함께 수동 회전
- 후면/전면 카메라 전환
- 플래시 끔/자동/켬
- 핀치 줌과 탭 포커스
- 촬영 사진을 `Pictures/GhostCamera` 앨범에 저장
- 기준 사진이 있으면 촬영 직후 `BEFORE / AFTER` 비교 화면 표시
- 비교 화면에서 필요할 때만 `2400 x 1600` B/A 콜라주 저장
- 고스트 투명도·비율과 카메라 회전값을 다음 실행에도 유지

고스트 사진은 촬영 구도를 맞추는 용도로만 화면에 표시되며 저장되는 사진에는 포함되지 않습니다. 앱은 인터넷 권한을 요청하지 않습니다.

## 화면 기준

- 주 촬영 환경: 대형 갤럭시 탭 세로 모드
- 지원 화면: Android 휴대폰·태블릿의 세로/가로 모드
- 상태바, 내비게이션 바, 태블릿 작업 표시줄을 피해 촬영 컨트롤 배치
- 화면 회전 후에도 선택한 기준 사진과 투명도 유지

## 기기 없이 테스트

개발 중에는 오픈소스 QEMU 기반 [Android Emulator](https://developer.android.com/studio/run/emulator)를 사용합니다. 에뮬레이터 카메라의 Virtual Scene으로 CameraX 미리보기와 촬영 흐름을 검증할 수 있습니다.

현재 API 35에서 확인한 화면 조합은 다음과 같습니다.

| 프로필 | 세로 | 가로 |
| --- | --- | --- |
| 대형 태블릿 `1600 x 2560` | 확인 | `2560 x 1600` 확인 |
| 휴대폰 `1080 x 2400` | 확인 | `2400 x 1080` 확인 |

에뮬레이터에서는 Logitech BRIO 웹캠으로 전체 화면 프리뷰, 기준 사진 5장 탐색, 투명도·비율·카메라와 고스트의 동시 회전 및 재실행 후 유지, 촬영 파일의 `Pictures/GhostCamera` 저장과 회전 메타데이터를 확인했습니다. 촬영 직후 B/A 비교, 촬영 당시 기준 사진 회전 유지, 화면 회전 후 촬영 쌍 유지, `2400 x 1600` 콜라주 생성도 검증했습니다. 삼성 카메라 HAL과 One UI 차이는 실제 Galaxy 하드웨어인 [Samsung Remote Test Lab](https://developer.samsung.com/remote-test-lab) 또는 실기기에서 최종 확인해야 합니다.

## 빌드

JDK 17과 Android SDK 35가 필요합니다.

```powershell
./gradlew testDebugUnitTest lintDebug assembleDebug
```

생성 APK: `app/build/outputs/apk/debug/app-debug.apk`
